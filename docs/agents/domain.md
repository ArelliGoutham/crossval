# Domain documentation

This is a single-context repository.

Before working in the codebase, agents must read:

1. `CONTEXT.md` for domain vocabulary, module boundaries, and invariants.
2. Relevant ADRs under `docs/adr/` for settled technical and product decisions.
3. `AGENTS.md` for implementation and quality rules.

Use the terms defined in `CONTEXT.md` in code, tests, API contracts, documentation, and issue titles. If a proposed change conflicts with an ADR, surface the conflict explicitly and seek approval before proceeding.
